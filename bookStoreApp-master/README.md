# Book Store App

This is a full-stack Book Store application. Frontend uses Vite + React and Backend is a Node.js/Express server.

Quick start

1. Install dependencies for frontend and backend.

   Backend:
   - cd Backend
   - npm install

   Frontend:
   - cd Frontend
   - npm install

2. Run in development

   - Start backend: `npm run dev` (from Backend)
   - Start frontend: `npm run dev` (from Frontend)

Notes

- Add your environment variables in `Backend/.env` as needed.
- Use GitHub Desktop to create a new repository from this local folder and publish to GitHub.
